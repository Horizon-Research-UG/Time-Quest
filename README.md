# Münzwurf Spiel 🪙

**Live Demo:** [Spiel jetzt spielen!](https://horizon-research-ug.github.io/Time-Quest/)

Interaktives Münzwurf-Spiel mit realistischer Animation und einstellbarer Drehzeit.

## 🎮 Spielfeatures

- 🎯 **Einfach klicken:** Münze anklicken zum Werfen
- 🌪️ **Realistische Animation:** Flug, Drehung und Sprunganimation
- ⏱️ **Einstellbare Drehzeit:** 1-10 Sekunden wählbar
- 🎲 **Echter Zufall:** 50/50 Chance für Kopf 👑 oder Zahl 💰
- 🏀 **Sprungeffekt:** Münze springt beim Landen mehrmals

## 🚀 Direkt spielen

Das Spiel läuft direkt im Browser auf GitHub Pages:
**https://horizon-research-ug.github.io/Time-Quest/**

## 📱 Spielanleitung

1. **Münze werfen:** Klicke auf die Münze 💰
2. **Drehzeit einstellen:** Nutze den Slider (1-10 Sekunden) 
3. **Ergebnis abwarten:** Kopf 👑 oder Zahl 💰
4. **Erneut spielen:** Klicke wieder auf die Münze
